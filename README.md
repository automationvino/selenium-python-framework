# Selenium Python Automation Framework

A Selenium automation framework developed using **Python**, **Pytest**, and the **Page Object Model (POM)** design pattern. This framework supports **data-driven testing** using Excel and generates HTML test reports.

---

## 🚀 Technologies Used

- Python 3.13
- Selenium WebDriver
- Pytest
- OpenPyXL
- Page Object Model (POM)
- Git & GitHub
- HTML Reports

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/automationvino/selenium-python-framework.git
```

Navigate to the project:

```bash
cd selenium-python-framework
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Tests

Run all tests:

```bash
pytest
```

Generate HTML Report:

```bash
pytest --html=reports/report.html
```
